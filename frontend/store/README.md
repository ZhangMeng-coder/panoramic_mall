# store — 全景商城店铺端（店主侧）

店主端的页面工程（Vue 3 + Vite + **TypeScript** + Element Plus），端口 **5174**：经网关**只访问端 BFF `store-bff`**（:8084）——店铺 / 商品 / 库存数据由 store-bff 内部 Feign 落 store 域，分类 / 品牌与中台模板比对也经它调 goods-center。

页面域：注册 / 登录、店铺信息（核心页）、在售商品与 SKU、库存管理、订单管理（列表 + 详情弹窗 + 发货）。

## 业务边界

- **本端没有 `@PreAuthorize`，也不应有**：店主登录后对自己店全权限——权限维度只存在于 admin 端，别把「controller 里没有 `@PreAuthorize`」当缺陷去补（见 [docs/contracts/store-bff.md](../../docs/contracts/store-bff.md) 第二节：全 23 个接口都没有 `@PreAuthorize`）。
- 「店铺信息」按 `store_shop.status`（0 草稿 / 1 待审核 / 2 已通过 / 3 已驳回）驱动表单只读 / 可编辑与可用的操作按钮；商品、订单、库存这些开店后业务入口**仅审核通过（status=2）可见可进**——路由守卫在进入前先拉一次「我的店铺」，未通过一律回店铺信息页。

## 商品管理的两条弹窗分工

- **基本信息弹窗**（新增/编辑）：商品名称/叶子分类/品牌/主图/轮播图/富文本详情 + **规格属性配置**（各规格维度→可选项）+ 上下架只读标签。新增时可按中台 `sku_code` 整单预填，也可在同一弹窗里按规格组合直接建 SKU；编辑时 SKU 维护移交「规格」弹窗，规格配置在存在已上架 SKU 时只读。
- **规格弹窗**（SKU 管理）：SKU 行表格（规格列/价格/编码/图片/**上下架开关**/删除），保存走整单替换。已上架行**整行只读且禁用删除**；上下架开关即时生效并由后端**联动商品上下架**（上架任一 SKU → 商品上架；SKU 全下架 → 商品下架），商品状态因此在列表页只读展示。初始库存只有新建行可填，已有行的库存在「库存管理」页维护。

关联中台的商品（`goodsSpuId != null`）：编辑时若中台版本戳已变，顶部提示「中台模板已更新」并给「同步中台」按钮——点则用中台当前内容覆盖商品信息与规格（不同步也可正常保存）；中台模板已删则提示「已不存在」。「规格」弹窗另有「同步中台 SKU」：按 `sku_code` 对齐、保留已填价格、中台新行价格留空，已上架行跳过。

## 平台锁定：只读呈现

商品可被平台管理员锁定，店铺端**只能查看、不能改**：

- 列表新增「锁定状态」列（`lockStatus === 1` → 红色「已锁定」，否则「正常」）；
- 已锁定行：`编辑` / `规格` / `删除` 一律**禁用**，只多出 `锁定信息` 按钮 → 弹窗只读展示 **锁定原因 + 锁定时间**（按产品口径**不展示锁定人**）；
- 锁定时平台会把该商品全部 SKU 级联下架、商品随之变为「已下架」；**解锁后不会自动恢复上架**，需店主自行重新上架；
- 前端禁用只是提示，**真正的拦截在 store 域**（锁定期 owner 侧编辑/删除/改 SKU/上下架一律拒绝，提示「商品已被平台锁定…请联系平台管理员」）。

## 本地开发

```bash
npm install
npm run dev        # → http://localhost:5174（需网关 8080 与 store-bff 8084 已启动，且库已建表）
npm run type-check # vue-tsc --noEmit（只查类型，不出产物）
npm run build      # vue-tsc --noEmit && vite build，产物输出 dist/
```

`vite.config.ts` 把 `/store` 转发到网关 8080。登录态是轻量模块（`src/store/auth.ts`）：token 持久化在 `localStorage`、用户信息驻留内存，刷新后由路由守卫拉 `/auth/me` 重建；明暗主题的首帧防闪烁脚本见 `index.html`。

页面契约见 [docs/contracts/store-bff.md](../../docs/contracts/store-bff.md)。
