# Triage Labels

技能以五个规范 triage 角色来表述。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义                                   |
| -------------------------- | ----------------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`          | 需维护者评估该 issue                   |
| `needs-info`               | `needs-info`            | 等待报告者补充信息                     |
| `ready-for-agent`          | `ready-for-agent`       | 已完全明确,可交给 AFK agent 执行       |
| `ready-for-human`          | `ready-for-human`       | 需人工实现                             |
| `wontfix`                  | `wontfix`               | 不予处理                               |

本地 markdown tracker 下,这些串表现为 issue 文件顶部的 `Status:` 值。

技能提到某个角色时(如「apply the AFK-ready triage label」),使用本表对应行的标签串。要改用别的词表时,只改右列。
